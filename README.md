# 🕋 NurSafar — The Ultimate Umrah Super App

![NurSafar Hero Banner](/images/hero-banner.png)

**NurSafar** is a premium, multi-domain "Super App" designed to streamline and enhance the pilgrimage experience for Umrah travelers. It serves as a unified ecosystem connecting pilgrims with verified service providers, including tour agencies, transportation experts, and crowdfunding opportunities.

---

## 🚀 Overview

The project aims to solve the complexities of planning a pilgrimage by providing a single, trusted platform. Whether it's booking a comprehensive tour package, arranging private transit, or participating in a community-driven crowdfunding campaign, NurSafar brings technology and spirituality together.

### 🌟 Key Features

-   **Verified Umrah Packages**: A curated marketplace for high-quality tour packages from trusted agencies.
-   **Logistics & Transit**: Specialized services for border transit and private transportation with professional drivers.
-   **Crowdfunding for Pilgrimage**: A unique module to facilitate community support for those who need financial assistance for their sacred journey.
-   **Multi-Role Access**: Dedicated portals and workflows for **Pilgrims**, **Tour Agencies (Partners)**, and **Drivers**.
-   **Multi-Language Support**: Fully localized interface in **English**, **Russian**, and **Tajik**.
-   **Modern Dashboard**: Advanced analytics and management tools for partners and admins.

## 🛠 Tech Stack

### 🖥 Frontend
-   **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
-   **Animations**: [Framer Motion](https://www.framer.com/motion/)
-   **State Management**: [Redux Toolkit](https://redux-toolkit.js.org/) & [RTK Query](https://redux-toolkit.js.org/rtk-query/overview)
-   **Components**: [Radix UI](https://www.radix-ui.com/) & [Lucide React](https://lucide.dev/)
-   **Internationalization**: [next-intl](https://next-intl-docs.vercel.app/)

### ⚙️ Backend (Architecture)
-   **Framework**: [NestJS](https://nestjs.com/)
-   **ORM**: [Prisma](https://www.prisma.io/)
-   **Database**: [PostgreSQL](https://www.postgresql.org/)
-   **API Documentation**: [Swagger/OpenAPI](https://swagger.io/)
